# Sprite2D في Godot

**تاريخ التحقق:** 18 أكتوبر 2026  
**نسخة Godot المستقرة عند التحقق:** 4.7.2  
**مصدر التوثيق:** صفحة `stable` الرسمية لـ Godot.

> يوجد Godot 4.8 حاليًا بحالة beta، لذلك هذه الملاحظات تعتمد توثيق الفرع المستقر، لا نسخة تجريبية.

## ما هو Sprite2D؟

`Sprite2D` عقدة ثنائية الأبعاد عامة لعرض صورة `Texture2D`. يمكنها عرض صورة كاملة، جزءًا من أطلس صور، أو إطارًا من صورة مقسّمة إلى شبكة إطارات. ترث من `Node2D`، ولذلك يمكن تحريكها وتدويرها وتغيير مقياسها ضمن مشهد 2D.

## الخصائص الأكثر استخدامًا

| الخاصية | الاستخدام |
| --- | --- |
| `texture` | تعيين الصورة المراد رسمها. |
| `centered` | يجعل مركز الصورة عند موضع العقدة؛ القيمة الافتراضية `true`. عند استخدام فن البكسل قد يبدو الرسم مشوهًا إذا وقع موضعه بين البكسلات. يمكن تعطيله أو استخدام إعدادات محاذاة 2D إلى البكسل. |
| `offset` | إزاحة موضع رسم الصورة نسبةً إلى العقدة. زيادة `offset.y` تحرك الصورة إلى أسفل لأن محور Y موجب إلى الأسفل في 2D. |
| `flip_h`, `flip_v` | قلب الصورة أفقيًا أو عموديًا. |
| `hframes`, `vframes` | عدد أعمدة وصفوف شبكة الإطارات داخل الصورة. الافتراضي لكل منهما `1`. |
| `frame` | رقم الإطار الذي سيظهر من شبكة الإطارات. يبدأ العد من `0`. |
| `frame_coords` | تحديد الإطار باستخدام إحداثيات العمود والصف بدل رقم الإطار. يلزم أن يكون `hframes` أو `vframes` أكبر من `1`. |
| `region_enabled` | تفعيل اقتطاع مستطيل من صورة أطلس. |
| `region_rect` | مستطيل المنطقة المراد عرضها من الأطلس، عند تفعيل `region_enabled`. |
| `region_filter_clip_enabled` | يقصّ ترشيح الصورة عند حدود المنطقة لتجنب تسرب بكسلات من المناطق المجاورة؛ يتطلب تفعيل `region_enabled`. |

عند تغيير عدد الأعمدة أو الصفوف، تحاول Godot الحفاظ على الإطار المرئي نفسه؛ وإذا لم يعد ذلك ممكنًا تعيد `frame` إلى `0`.

## مثال: عرض إطار من Sprite Sheet

لنفترض أن صورة الشخصية شبكة من 4 أعمدة و2 صفوف:

```gdscript
extends Sprite2D

func _ready() -> void:
    hframes = 4
    vframes = 2
    frame = 0 # أول إطار

func _process(_delta: float) -> void:
    if Input.is_action_just_pressed("ui_right"):
        frame = (frame + 1) % (hframes * vframes)
```

يمكن بدلًا من رقم الإطار تعيين موقعه في الشبكة:

```gdscript
frame_coords = Vector2i(2, 1) # العمود الثالث، الصف الثاني
```

تأكد أن الصورة مقسّمة بالتساوي كما تتوقع قيم `hframes` و`vframes`؛ وإلا فقد لا تقع حدود الإطارات على مواضع الصورة المطلوبة.

## الأطالس ومناطق الصورة

استخدم `region_enabled = true` ثم اضبط `region_rect` لتحديد المستطيل المراد رسمه من صورة أكبر. إذا كانت هناك خطوط أو بكسلات متسربة من الأجزاء المجاورة، جرّب `region_filter_clip_enabled = true`.

**ملاحظة للمظللات:** عند استخدام Shader مخصص مع `Sprite2D`، قيمة `UV` تشير إلى مساحة الصورة كاملة. للحصول على المنطقة المعروضة فعليًا من الأطلس، راجع القيمة المضمنة `REGION_RECT` في مظللات `CanvasItem`.

## الدوال والإشارات

- `get_rect()` يعيد حدود `Sprite2D` بإحداثياتها المحلية. يمكن استخدامه لفحص نقطة محلية، مثل اختبار نقر الفأرة بعد تحويل موضعها إلى `to_local(...)`.
- `is_pixel_opaque(pos)` يفحص إن كانت البكسلة عند الموضع المحلي معتمة؛ يعيد `false` إذا كان الموضع خارج الحدود أو لم تُعيّن صورة.
- `frame_changed()` تصدر عند تغير الإطار.
- `texture_changed()` تصدر عند تغير الصورة.

مثال مبسط لاختبار النقر داخل حدود العقدة:

```gdscript
func _input(event: InputEvent) -> void:
    if event is InputEventMouseButton \
    and event.pressed \
    and event.button_index == MOUSE_BUTTON_LEFT:
        if get_rect().has_point(to_local(event.position)):
            print("تم النقر على الصورة")
```

## متى أستخدم AnimatedSprite2D؟

`Sprite2D` مناسب لعرض صورة أو اختيار إطار والتحكم به يدويًا. إذا أردت إدارة رسوم متحركة بأسماء وسرعات وتشغيل وإيقاف من موارد `SpriteFrames`، فتوثيق Godot يشرح استخدام `AnimatedSprite2D`. كما يمكن تحريك خاصية الإطار في `Sprite2D` باستخدام `AnimationPlayer`.
